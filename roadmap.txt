1. EXECUTIVE OVERVIEW & CURRENT SEO AUDIT SUMMARY
--------------------------------------------------------------------------------
A full audit of the codebase revealed several strong foundations:
  * Clean, human-readable slug-based URL architecture (/services/{slug}, /blog/{slug}).
  * A well-equipped Blog module supporting schema and custom meta fields.
  * Mobile-friendly responsive layouts with standard viewport configuration.

However, the application currently suffers from critical SEO blockers:
  [CRITICAL] Industry detail pages (/industries/{slug}) do not output their
             meta_title or meta_description, causing identical duplicate title
             tags across all industry pages.
  [CRITICAL] No XML Sitemap exists (/sitemap.xml is missing entirely).
  [CRITICAL] robots.txt does not disallow /admin/ and lacks a Sitemap reference.
  [CRITICAL] Canonical tags are missing on ~80% of pages (including the Homepage).
  [CRITICAL] Open Graph (og:*) and Twitter Card tags are completely missing in the
             global layout, breaking social sharing on LinkedIn, WhatsApp, and X.
  [HIGH]     No Organization, LocalBusiness, or WebSite Schema exists on the Homepage.
  [HIGH]     8 identical <h2> tags are hardcoded in the header menu and footer on
             every single page, distorting the document heading outline.
  [HIGH]     Legacy fallback route /{section}/{slug} attempts to load non-existent
             view catalog.show (triggers 500 error if hit).
  [MEDIUM]   Core Web Vitals bottlenecks: 17.6MB background video, 1.8MB uncompressed
             PNG certificate image, and client-side Tailwind CDN on service pages.
  [MEDIUM]   Missing custom 404 error page (resources/views/errors/404.blade.php).

1.1 Fix Duplicate Title & Description on Industry Detail Pages
--------------------------------------------------------------------------------
File: resources/views/industries/show.blade.php
Problem:
  The Industry model has meta_title, meta_description, canonical_url, and og_image
  stored in the database, but resources/views/industries/show.blade.php never sets
  @section('title') or @section('description'). All industry pages fall back to
  the homepage title ("Retrotech - Business Made Easy").
Action:
  Add the following directives at the very top of resources/views/industries/show.blade.php:
  ------------------------------------------------------------------------------
  @extends('layouts.app')

  @section('title', $industry->meta_title ?: ($industry->name . ' IT & Digital Solutions | Retrotech'))
  @section('description', $industry->meta_description ?: ($industry->short_description ?: 'Comprehensive ' . $industry->name . ' technology solutions by Retrotech Digital.'))

  @push('head')
    <link rel="canonical" href="{{ $industry->canonical_url ?: route('industries.show', $industry->slug) }}">
    <meta property="og:title" content="{{ $industry->meta_title ?: $industry->name }}">
    <meta property="og:description" content="{{ $industry->meta_description ?: $industry->short_description }}">
    <meta property="og:url" content="{{ route('industries.show', $industry->slug) }}">
    @if(!empty($industry->og_image ?: $industry->hero_image))
      <meta property="og:image" content="{{ asset($industry->og_image ?: $industry->hero_image) }}">
    @endif
  @endpush
  ------------------------------------------------------------------------------

1.2 Fix Missing / Broken Fallback Catalog Route
--------------------------------------------------------------------------------
File: routes/web.php (Line 185)
Problem:
  Route::get('/{section}/{slug}') attempts to render view('catalog.show').
  The file resources/views/catalog/show.blade.php does not exist, causing 500
  Internal Server Error when matched.
Action:
  Either create resources/views/catalog/show.blade.php as a graceful fallback
  landing page, or change the route fallback to return abort(404) safely:
  ------------------------------------------------------------------------------
  Route::get('/{section}/{slug}', function (string $section, string $slug) {
      abort(404);
  })->where('section', 'services|industries');
  ------------------------------------------------------------------------------

3.2 Build Dynamic XML Sitemap Controller & Route
--------------------------------------------------------------------------------
Create Controller: app/Http/Controllers/SitemapController.php
Create Route in routes/web.php:
  Route::get('/sitemap.xml', [SitemapController::class, 'index'])->name('sitemap');

Implementation details for SitemapController:
  - Query all published resources from the database:
    * Static core pages (/, /about-us, /services, /industries, /blog, /faqs, /careers, /contact)
    * Service::all()
    * TechDevelopment::where('is_published', true)->get()
    * Industry::where('is_published', true)->get()
    * BlogPost::where('is_published', true)->get()
    * WebPage::where('is_published', true)->get()
  - Format output as application/xml with standard schema:
    <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
      <url>
        <loc>https://retrotechdigital.com/services/web-development</loc>
        <lastmod>2026-11-10T00:00:00+00:00</lastmod>
        <changefreq>weekly</changefreq>
        <priority>0.8</priority>
      </url>
      ...
    </urlset>
  - Cache response for 24 hours using Cache::remember('sitemap.xml', 86400, ...)
    to guarantee sub-10ms response time for search engine bots.

Goal: Maximize PageSpeed score and pass Google Core Web Vitals (LCP, INP, CLS).

6.1 Background Video Optimization (LCP & Mobile Bandwidth)
--------------------------------------------------------------------------------
File: resources/views/partials/hero-video.blade.php
Problem:
  retro_light.mp4 is 17.6 MB and preloads automatically.
Action:
  - Compress retro_light.mp4 using Handbrake / ffmpeg (H.264 CRF 26 / WebM VP9).
    Target size: < 3.5 MB.
  - Add poster="{{ asset('assets/images/hero-video-poster.webp') }}" to <video>.
  - Set preload="none" on mobile viewports (< 768px).

6.2 Image Format Conversion & Modern Compression
--------------------------------------------------------------------------------
Files:
  * public/assets/images/certificate.png (currently 1.8 MB!)
    - Convert to WebP / compressed SVG. Target size: < 120 KB.
  * public/assets/images/tech-development/*.jpg (700 KB - 875 KB each)
    - Convert to WebP format with 80% quality. Target size: < 90 KB each.
  * Always include explicit width and height attributes on <img> tags (especially
    brand logos in header & footer) to eliminate Cumulative Layout Shift (CLS).

6.3 Eliminate Runtime Tailwind Play CDN
--------------------------------------------------------------------------------
Files:
  * resources/views/service-page.blade.php (Line 7)
  * resources/views/web-page.blade.php (Line 7)
Problem:
  These templates load <script src="https://cdn.tailwindcss.com"></script> at runtime.
  This script is >300KB, runs client-side JIT compilation in the browser, blocks
  rendering, and causes severe layout shifts.
Action:
  Import the needed utilities directly in resources/css/app.css and bundle them
  via Vite (@vite(['resources/css/app.css', 'resources/js/app.js'])).
  Remove the <script src="https://cdn.tailwindcss.com"> tag.

6.4 CSS Cache-Busting Optimization
--------------------------------------------------------------------------------
File: resources/views/tech_development/show.blade.php (Line 8)
Problem:
  href="{{ asset('css/tech-development.css') }}?v={{ time() }}"
  Forces browser to download the CSS on every single request, disabling caching.
Action:
  Change to filemtime:
  ?v={{ file_exists(public_path('css/tech-development.css')) ? filemtime(public_path('css/tech-development.css')) : '1.0' }}
